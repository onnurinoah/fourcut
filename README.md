# 인생네컷 — 웹캠 포토부스

스마트폰이나 PC 웹캠으로 **여덟 장을 찍고 → 네 장을 고르고 → 매수를 정해 → 인쇄**하는
한 장짜리 페이지입니다. 사진은 서버로 올라가지 않고 **그 기기 안에서만** 처리됩니다.

화면은 **1920×1080 한 화면**으로 짜여 있습니다. 무대를 그 크기로 고정해 두고 창 크기에
맞춰 통째로 배율만 줄이므로, 부스 모니터·노트북·빔프로젝터 어디에 띄워도 같은 배치가 나옵니다.

첫 화면에는 배경 그림과 버튼 둘 — **네컷 촬영하기**, **청사진 촬영하기** 뿐입니다. 인화 규격·카메라·프린터·프레임
템플릿·꾸미기 같은 설정은 모두 오른쪽 위 **톱니바퀴(관리자 설정)** 안으로 들어가 있어,
손님에게는 보이지 않습니다. 관리자 창은 바깥을 누르거나 `Esc` 로 닫습니다.

```
index.html                      페이지 전부 (HTML·CSS·JS 한 파일)
assets/home.jpg                 첫 화면 배경 그림
frames/                         프레임 템플릿 이미지 + frames.json
server/print-server.js          인쇄 서버 + QR 공유 + AI 변환 (Node 18+, 설치할 것 없음)
server/toon.config.example.json AI 변환을 쓸 때 복사해 채우는 설정 보기
```

## 1. 제일 빠른 길 — 인쇄까지 자동으로

프린터가 꽂힌 노트북/PC 에서 터미널을 열고:

```bash
node server/print-server.js
```

그리고 그 컴퓨터의 브라우저로 **http://localhost:8787** 을 엽니다. 끝입니다.

- `localhost` 라서 카메라 권한이 정상으로 열립니다 (카메라는 https 또는 localhost 에서만 켜집니다)
- 톱니바퀴 → **프린터** 칸에 초록 불이 들어오고, 연결된 프린터 목록이 뜹니다
- **인쇄** 버튼을 누르면 대화상자 없이 곧바로 프린터로 나갑니다

프린터를 하나로 고정하려면:

```bash
node server/print-server.js --printer "Canon SELPHY CP1500" --port 8787
```

| 옵션 | 뜻 |
|---|---|
| `--port 8787` | 포트 (기본 8787) |
| `--printer "이름"` | 프린터 고정. 페이지에서 고른 값보다 우선합니다 |
| `--host 0.0.0.0` | 같은 와이파이의 다른 기기에서도 접속 허용 |
| `--lan` | 위와 같되, **QR 로 사진 받기** 까지 켭니다 (아래 3장) |
| `--tunnel` | cloudflared 로 공개 주소를 열어, 다른 망의 폰도 받게 합니다 |
| `--public <주소>` | 터널 주소를 직접 넣습니다 (이름 있는 터널을 쓸 때) |
| `--no-fit` | CUPS 의 `fit-to-page` 를 끕니다 (여백이 생길 때) |

서버가 하는 일은 하나입니다. 페이지가 보낸 PNG 를 임시 파일로 저장한 뒤
macOS·리눅스는 `lp`, 윈도우는 `mspaint /pt` 로 인쇄를 거는 것. 1분 뒤 임시 파일은 지워집니다.

## 2. 서버 없이 — 크롬 키오스크 인쇄

서버를 띄우기 번거로우면, 크롬을 **인쇄 대화상자 없이** 띄우는 방법이 있습니다.
기본 프린터로 바로 나갑니다.

```bash
# macOS
open -a "Google Chrome" --args --kiosk-printing --kiosk https://내주소

# Windows (바로가기 속성 → 대상 뒤에 붙이기)
chrome.exe --kiosk-printing --kiosk https://내주소
```

`--kiosk` 까지 넣으면 전체화면 무인 부스가 됩니다. 종료는 `Alt+F4`.
이 방법에서는 **매수만큼 페이지를 겹쳐 보내서** 원하는 장수를 뽑습니다.

둘 다 안 되면? 그냥 평범한 인쇄창이 뜹니다. 페이지는 항상 이 순서로 시도합니다.

> 인쇄 서버 → (없으면) 브라우저 인쇄 → 언제든 **저장** 버튼으로 PNG 내려받기

## 3. 찍은 사진을 폰으로 — QR

인쇄한 종이 말고 **사진 파일**을 가져가고 싶을 때 씁니다. 인쇄 서버를 `--lan` 으로 띄우면
됩니다.

```bash
node server/print-server.js --lan
```

뜨는 안내에 `폰   http://192.168.0.12:8787/d` 처럼 주소가 찍힙니다. **이 주소는 바뀌지
않습니다.** 그래서 QR 도 하나뿐입니다 — 미리보기 화면의 사진 옆에 늘 떠 있고, 원하면
종이에 뽑아 부스에 붙여 둬도 그대로 맞습니다.

손님이 할 일은 하나입니다. **휴대폰 카메라로 QR 을 비추는 것.** 저장 버튼도 없이 사진
파일이 바로 내려옵니다 (아이폰은 "다운로드하시겠습니까" 를 한 번 물어봅니다).

| 언제 | 폰에서 벌어지는 일 |
|---|---|
| 찍고 나서 비추면 | 사진 파일이 바로 내려받아집니다 |
| 찍기 전에 비추면 | 기다리는 화면이 뜨고, 부스에서 찍는 순간 저절로 내려받습니다 |
| 다음 사람이 시작하면 | 앞 사진은 사라지고 다시 기다리는 화면 |

### 같은 와이파이가 아니어도 되게 — 터널

위 주소는 사설 랜 주소라 같은 와이파이에서만 닿습니다. 손님이 셀룰러를 쓰든 다른 망에
있든 열리게 하려면 터널을 씁니다. [cloudflared](https://developers.cloudflare.com/cloudflared)
를 깔아 두고:

```bash
node server/print-server.js --tunnel
```

서버가 cloudflared 를 대신 띄우고, 몇 초 뒤 `https://....trycloudflare.com/d` 주소를
받아 QR 에 넣습니다. 부스 화면을 한 번 새로고침하면 QR 이 그 주소로 바뀝니다.

- 사진은 여전히 **부스 컴퓨터에서만** 나갑니다. 터널은 길만 내줄 뿐 클라우드에 저장하지
  않습니다
- 대신 **띄울 때마다 주소가 바뀝니다.** 종이로 뽑아 붙여 두는 고정 QR 은 이때 쓸 수
  없습니다 (화면의 QR 은 그대로 잘 됩니다)
- 주소를 고정하려면 Cloudflare 계정과 도메인으로 이름 있는 터널을 만든 뒤
  `--public https://내주소` 로 넘기면 됩니다
- 터널을 여는 동안은 그 주소를 아는 사람이면 누구나 지금 사진을 볼 수 있습니다.
  행사가 끝나면 서버를 끄세요

서버가 들고 있는 사진은 **늘 한 장**입니다. 다음 사람이 **촬영 시작**을 누르거나 앞
사람이 **처음으로** 를 누르면 그 자리에서 버려집니다. 30분이 지나도 저절로 사라집니다.

- 폰과 부스 컴퓨터가 **같은 와이파이**에 있어야 합니다. 랜 주소는 그 안에서만 닿습니다
- 사진은 인터넷 어디로도 올라가지 않습니다. 부스 컴퓨터의 **메모리에만** 머무르고,
  디스크에는 쓰지 않습니다. 서버를 끄면 그 순간 없어집니다
- 뒤집어 말하면, 같은 와이파이에 있는 사람은 누구나 그 주소로 **지금 사진**을 볼 수
  있습니다. 고정 QR 의 값이자 대가입니다. 모르는 사람이 많은 망에서는 `--lan` 을 켜지 마세요

`--lan`/`--tunnel` 없이 띄웠거나 서버가 없으면, QR 자리에 무엇을 해야 하는지 그대로
적혀 나옵니다.

QR 은 페이지가 직접 그립니다. 외부 라이브러리도, 인터넷도 필요 없습니다.

## 4. 청사진 촬영하기 — 사진을 그림으로

첫 화면에는 버튼이 둘입니다. **네컷 촬영하기** 는 사진 그대로, **청사진 촬영하기** 는
파란 그림체로 뽑습니다. 찍는 방법은 똑같고 결과물만 다릅니다.

청사진은 두 가지 방식으로 돌아갑니다.

### 가) 그냥 켜면 — 페이지 안의 청사진 필터 (기본)

설치할 것도, 인터넷도, 돈도 들지 않습니다. 사진의 명암을 네 단으로 뭉개 면을 만들고
큰 윤곽을 밝은 선으로 얹어, 짙은 남색 바탕의 도면 같은 그림으로 바꿉니다. 즉시 나오고
사진은 그 기기 밖으로 나가지 않습니다.

**다만 이건 필터입니다.** 사진에 없던 것을 그려 넣지 못합니다 — 예수님을 함께 넣으려면
아래 나) 가 필요합니다.

### 나) 이미지 생성 AI 붙이기 — 예수님이 함께 계신 그림

외부 이미지 생성 서비스에 사진을 보내 **그림을 새로 그려** 받아 옵니다. 업체마다 요청
모양이 달라서 코드에 박아 두지 않고 설정 파일로 받습니다.

```bash
cp server/toon.config.example.json server/toon.config.json
# 파일을 열어 쓰실 업체의 주소·헤더·본문 이름을 채우세요
export TOON_API_KEY=발급받은키
node server/print-server.js --tunnel
```

`server/toon.config.json` 이 있으면 **청사진 촬영하기** 가 자동으로 AI 쪽으로 갑니다.
고른 넉 장을 한꺼번에 보내고, 되는 대로 받아 인화지에 앉힙니다. 실패하면 조용히 가)
필터로 내려가고 화면에 그렇게 적힙니다.

설정 파일에서 서버가 채워 주는 자리:

| 자리 | 들어가는 값 |
|---|---|
| `${IMAGE_DATA_URL}` | `data:image/jpeg;base64,...` 형태의 사진 |
| `${IMAGE_B64}` | 머리말 없는 base64 사진 |
| `${PROMPT}` | 설정 파일의 `prompt` 값 |
| `${아무_대문자_이름}` | 같은 이름의 환경변수 (키는 여기로 주세요) |

`imagePath` 는 응답에서 그림을 꺼낼 경로입니다 (`data.0.b64_json` 처럼 점으로 잇습니다).
그림 대신 "만드는 중" 을 돌려주는 업체는 `poll` 을 채우면 다 될 때까지 물어봅니다.

**먼저 알고 계셔야 할 것:**

- **손님 얼굴이 그 업체 서버로 올라갑니다.** 지금까지의 "사진은 이 기기 밖으로 안
  나간다" 가 이 기능에서만 깨집니다. 부스에 안내문을 붙이시고, 미성년자는 보호자
  동의를 받으세요
- 사진 한 장당 요금이 붙습니다. 한 사람에 **넉 장**이 나갑니다
- 한 사람에 20~40초쯤 걸립니다. 줄이 길면 가) 로 두는 편이 낫습니다
- 인터넷이 끊기면 가) 로 내려갑니다
- API 키는 설정 파일이 아니라 **환경변수**로 주세요. `server/toon.config.json` 은
  `.gitignore` 에 들어 있습니다

## 5. 스마트폰으로 찍으려면

폰 카메라를 쓰려면 페이지가 **https** 여야 합니다. 두 가지 방법이 있습니다.

화면이 16:9 고정이라 폰은 **가로로 눕혀야** 꽉 찹니다.

**A. 배포해서 쓰기 (간단)** — 이 저장소를 Vercel 에 올리면 `https://내주소` 로 열립니다.
폰에서 찍고 고르고, 인쇄는 폰의 **AirPrint / Mopria** 로 나갑니다 (인쇄창이 한 번 뜹니다).
자동 인쇄 서버 칸은 비워 두세요.

**B. 폰으로 찍고 자동 인쇄까지 (무인 부스)** — PC 에서 인쇄 서버를 띄운 뒤 https 통로를 하나 냅니다.

```bash
node server/print-server.js --host 0.0.0.0
cloudflared tunnel --url http://localhost:8787      # 또는 ngrok http 8787
```

발급된 `https://....trycloudflare.com` 주소를 폰으로 열면, 페이지와 인쇄 서버가 **같은 주소**라
카메라도 켜지고 인쇄도 자동입니다. 관리자 설정의 서버 주소 칸은 비워 두거나 그 https 주소를 그대로 넣으세요.

> https 페이지에서 `http://localhost` 로 인쇄를 보내는 방식은 크롬에서는 되지만
> 사파리·일부 브라우저가 막습니다. 그래서 위의 A·B 를 권합니다.

## 6. 골격과 인화 규격

기본 골격은 **2×2 프레임**입니다. 바깥 테두리는 얇고, 칸 사이는 가늘고, 아래에 넓은 띠가 남습니다.
받은 템플릿 이미지에서 잰 비율을 그대로 씁니다 (종이 기준 — 좌우 5.5%, 위 4.0%,
칸 사이 가로 2.4% · 세로 1.6%, 아래 띠 13.4% → 한 컷은 세로 0.71:1).
비율로 적어 두었기 때문에 **어떤 종이 크기를 골라도 같은 골격**이 나옵니다.

| 규격 | 종이 | 결과 |
|---|---|---|
| **4×6인치 · 2×2 프레임** (기본) | 101.6×152.4mm (1200×1800px) | 네 컷을 한 장에, 자를 필요 없음 |
| **5×7인치 · 2×2 프레임** | 127×178mm | 받은 템플릿의 가로세로 비에 가장 가까움 |
| **엽서 100×148 · 2×2 프레임** | 100×148mm | 캐논 셀피 CP 시리즈 엽서(L)용지 |
| **4×6인치 · 2컷 스트립 ×2** | 101.6×152.4mm | 5×15cm 스트립 두 장, 가운데를 자름 |
| **2×6인치 스트립** | 50.8×152.4mm | 스트립 한 장, 자를 필요 없음 |

한 컷의 비율은 골격에서 자동으로 계산되고, **촬영 화면의 미리보기도 그 비율로** 잘려 보입니다.
출력은 언제나 300dpi PNG 입니다.

## 7. 프레임 템플릿 이미지 쓰기

직접 그린 프레임 대신 **디자인한 이미지를 그대로** 쓸 수 있습니다. 인쇄 화면의
`BACKGROUND` 줄에서 고르고, 그 자리에서 `FILTER` 도 함께 고릅니다 (키오스크와 같은 순서).

**투명한 창을 뚫어 둔 PNG 를 권합니다.** 페이지가 알파 채널을 훑어 창을 자동으로 찾고,
사진을 그 뒤에 깐 다음 템플릿을 위에 덮습니다. 그래서 둥근 모서리도, 사진을 살짝 가리는
장식도 그대로 살아납니다.

1. 종이 크기에 맞춰 이미지를 만듭니다 (4×6인치라면 **1200×1800px @300dpi**)
2. 사진이 들어갈 자리를 **완전히 투명하게** 지웁니다 (네 칸)
3. 파일을 `frames/` 에 넣고 `frames/frames.json` 에 한 줄 적습니다

```json
[
  {
    "file": "my-frame.png",
    "label": "우리 교회 프레임",
    "paper": { "w": 101.6, "h": 152.4 },
    "slots": [
      { "x": 0.055, "y": 0.04,  "w": 0.433, "h": 0.405 },
      { "x": 0.512, "y": 0.04,  "w": 0.433, "h": 0.405 },
      { "x": 0.055, "y": 0.461, "w": 0.433, "h": 0.405 },
      { "x": 0.512, "y": 0.461, "w": 0.433, "h": 0.405 }
    ]
  }
]
```

`slots` 는 종이 전체를 1 로 본 비율이고, **적지 않아도 됩니다** — 투명한 창을 자동으로 찾습니다.
자리가 안 맞으면 관리자 설정의 템플릿 미리보기에서 **네모를 끌어 옮기고 모서리를 잡아 늘린 뒤**
`좌표 복사` 를 눌러 그 값을 `frames.json` 에 붙여 넣으세요. 그 기기에는 자동으로 기억됩니다.

- 투명한 부분이 없는 이미지(배경 그림)도 됩니다. 이때는 사진이 그림 **위에** 올라가고,
  네 칸 자리는 손으로 맞춥니다.
- 템플릿에 글자가 이미 인쇄돼 있으면 문구가 겹치니, 아래 문구는 **`아래 문구 넣기`** 를
  켤 때만 들어갑니다.
- 저장소에 파일을 두지 않고 **그 자리에서 불러오기**도 됩니다 (관리자 설정 → 템플릿 이미지 불러오기).
- 주소 뒤에 `?frame=my-frame.png` 를 붙이면 그 템플릿으로 바로 열립니다.

그 밖에 고를 수 있는 것: 사진 톤(원본·흑백·필름·화사·선명), 테두리 색(화이트·블랙·크림·네이비),
아래쪽 문구와 날짜, 좌우 반전(거울), 카운트다운 3초/5초, 인쇄 매수 1~20장.
고른 값은 그 기기에 기억됩니다.

```
?layout=frame-4x6 | frame-5x7 | frame-postcard | strip-4x6 | strip-2x6
?frame=<frames.json 의 파일 이름>
?agent=http://localhost:8787
```

## 8. 프린터별 메모

- **캐논 셀피 CP1500** — 엽서(P) 용지 + `엽서 100×148mm` 규격. 드라이버에서 "여백 없음"을 켜 두세요.
- **DNP·시티즌 염료승화 프린터** — 2×6 컷 모드를 프린터 쪽에서 먼저 켜야 `2×6인치` 가 제대로 나옵니다.
- **일반 잉크젯 + 4×6 인화지** — `4×6인치` 규격에 "테두리 없음(Borderless)" 설정을 함께 쓰세요.
- **가장자리가 잘려 나올 때** — 프린터의 확대 인쇄를 끄고, 서버를 `--no-fit` 으로 다시 띄웁니다.
- **색이 어둡게 나올 때** — 사진 톤을 `화사` 로 두면 인화지에서 한결 낫습니다.

## 9. 잘 안 될 때

| 증상 | 이유와 해결 |
|---|---|
| 카메라가 안 켜짐 | 주소가 `http://` 로 시작하면 (localhost 제외) 브라우저가 카메라를 막습니다. https 주소나 `http://localhost:8787` 로 여세요 |
| 카메라 목록이 비어 있음 | 브라우저 주소창 왼쪽 자물쇠 → 카메라 **허용** 후 새로고침 |
| 설정 화면이 안 보임 | 오른쪽 위 **톱니바퀴**를 누르세요. 설정은 전부 그 안에 있습니다 |
| 프린터 칸이 빨간 불 | 서버가 안 떠 있거나 주소가 다릅니다. `node server/print-server.js` 실행 후 **프린터 다시 확인** |
| QR 자리가 비어 있음 | 거기 적힌 문구가 답입니다. 대개는 인쇄 서버를 `--lan` 으로 띄우지 않은 경우입니다 |
| QR 은 찍히는데 페이지가 안 열림 | 폰이 부스 컴퓨터와 **같은 와이파이**인지 보세요. 손님용/게스트 망이 따로면 서로 못 닿습니다 |
| AI 변환이 안 됨 | 화면에 "청사진 필터로 뽑았습니다" 가 뜨면 서버 창의 `AI 변환 실패:` 줄을 보세요. 키·주소·본문 이름 중 하나가 틀린 경우가 대부분입니다 |
| 폰에 "아직 사진이 없습니다" | 아직 안 찍었거나, 다음 사람이 시작해서 앞 사진이 버려진 것입니다. 그 화면을 켜 둔 채 두면 찍는 순간 뜹니다 |
| 프린터 목록이 비어 있음 | macOS·리눅스는 `lpstat -a`, 윈도우는 PowerShell `Get-Printer` 가 프린터를 보여주는지 먼저 확인하세요 |
| 인쇄는 되는데 여백이 큼 | 프린터 드라이버의 용지 크기를 실제 인화지에 맞추고, "여백 없음"을 켜세요 |
| 아이폰에서 소리가 안 남 | 무음 스위치를 풀고, **촬영 시작**을 한 번 눌러 주면 그다음부터 납니다 |
| 화면이 작게 가운데만 나옴 | 16:9 고정 화면이라 세로 창에서는 위아래가 남습니다. 창을 가로로 넓히거나 전체화면(F11)으로 띄우세요 |
